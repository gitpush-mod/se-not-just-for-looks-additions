> **"NJFL gives Advanced flat atmo thrusters. Additions gives them Base and Upgraded siblings so the variant arrow feels complete."**

Addon for [**Not Just For Looks**](https://github.com/gitpush-mod/se-not-just-for-looks). NJFL takes the Flat Atmospheric Thrusters from **Warfare Evolution** and turns them into an Advanced tier. This mod adds the missing **Base** and **Upgraded** tiers, so the variant arrow on flat atmo thrusters cycles cleanly through all three.

  <img src="Not Just For Looks - Additions/thumb.jpg" alt="NJFL Additions preview" width="480" />
</p>

## ✨ What the variant arrow cycles

With both mods installed, cycling variants on a Flat Atmospheric Thruster gives you:

| Tier | Cost | Force | Superconductor tax | Comes from |
|---|---|---|---|---|
| **Base** | Vanilla | Vanilla (~1× thrust/mass) | None | *This mod* |
| **Upgraded** | 2× components | 4× force (~2× thrust/mass) | 10 / 5 / 4 / 2 (LG-L / LG-S / SG-L / SG-S) | *This mod* |
| **Advanced** | 3× components | 9× force (~3× thrust/mass) | Same SC scale + Reactor Component tax | *[NJFL](https://github.com/gitpush-mod/se-not-just-for-looks)* |

Covers all **8 flat atmo variants**: Large/Small thruster size × L-grid/S-grid × Flat/D-Shape geometry.

## 🧩 Works with or without NJFL

- **With NJFL installed** → full Base / Upgraded / Advanced cycle
- **Without NJFL** → you still get the new Base and Upgraded blocks; no Advanced tier on the variant arrow. Both work independently.

## 🚀 Install

1. [Subscribe on the Workshop page](https://steamcommunity.com/sharedfiles/filedetails/?id=3715057534)
2. (Optional but recommended) also subscribe to [NJFL](https://steamcommunity.com/sharedfiles/filedetails/?id=3572467804)
3. Enable both mods, build any Flat Atmospheric Thruster, and cycle the variant arrow

## 🎯 Compatibility

- ✅ **Space Engineers 1** — actively maintained
- ✅ **Save-safe**
- ✅ **Multiplayer + dedicated servers**
- ⚠️ **Overrides the vanilla Atmospheric Thruster variant group** — if another mod also restructures atmo thruster groups, mod load order matters
